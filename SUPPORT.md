# AssetFare support

For public product questions and reproducible non-sensitive defects, use the
issue tracker in the affected public repository or email
`support@assetfare.dev`.

- Service status and live route availability:
  <https://api.assetfare.dev/v2/status>
- Agent integration guide: <https://assetfare.dev/llms.txt>
- MCP and verifier issues:
  <https://github.com/assetfare/assetfare-mcp/issues>
- Dify integration issues:
  <https://github.com/assetfare/dify-plugin-assetfare/issues>
- smolagents integration issues:
  <https://github.com/assetfare/smolagents-assetfare/issues>

Do not post secrets, wallet capabilities, private keys, signed transactions, or
sensitive request data in an issue. Use the private security channel described
in `SECURITY.md` for vulnerabilities.
